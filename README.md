# AI SiteBuilder – AI-Powered Website Generator

AI SiteBuilder is a full-stack AI-powered web application that enables users to generate responsive website layouts from natural language prompts.
The application leverages Artificial Intelligence to automatically generate structured HTML and Tailwind CSS code, allowing users to build modern websites without manual coding.
It combines a React frontend, Node.js backend, AI integration, cloud database, and secure payment functionality to provide a seamless website creation experience.

## ✨ Features

- AI-powered website generation from text prompts
- Automatic HTML and Tailwind CSS code generation
- Responsive website layouts
- Interactive and user-friendly interface
- AI-powered prompt analysis and website creation
- Secure user authentication
- Subscription and payment integration with Stripe
- Cloud database integration using Neon PostgreSQL
- Fast and efficient full-stack architecture
- Public deployment using Vercel
